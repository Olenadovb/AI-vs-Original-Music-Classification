## Problem and motivation
The main problem addressed by our project is the transparency of music provenance. We investigate whether different music generation models leave characteristic acoustic "fingerprints" that can be used to determine not only whether an audio sample is AI-generated, but also which specific generator produced it.

This allows us to move beyond simple AI-generated vs. real music classification and explore the differences between generative models, as well as the possibility of identifying the specific source of generated audio.

## Data

The main dataset used in this project is [FakeMusicCaps](https://zenodo.org/records/15063698), which contains approximately 27,000 10-second audio clips generated by different text-to-music models using descriptions from MusicCaps. It will be used to study differences between generators and to build a closed-set classification system.

We also consider the [AIME dataset](https://huggingface.co/datasets/disco-eth/AIME), which contains 6,000 AI-generated tracks from 12 different models and services, together with 500 real tracks from MTG-Jamendo.

For comparison with real music, we plan to use [MusicCaps](https://huggingface.co/datasets/google/MusicCaps). [SunoCaps](https://www.kaggle.com/datasets/miguelcivit/sunocaps) will be used for an open-set experiment with a generator that is not present in the main training data.


## Approach

The main approach of the project is to search for acoustic "fingerprints" that are characteristic of different text-to-music generators. For each audio sample, we plan to extract handcrafted acoustic features describing spectral, temporal, rhythmic, and tonal properties of the signal, as well as embeddings from pretrained audio models.

First perform statistical analysis of the extracted features and investigate the structure of the feature and embedding spaces using PCA and UMAP. Also apply clustering to examine whether natural groups corresponding to different music generators emerge.

Then evaluate whether these characteristics remain consistent across different music prompts and datasets. To determine whether the extracted representations can be used to identify the source of an audio sample, we will use several baseline classification models, including:

- SVM
- Logistic Regression
- k-NN

Experiments will be conducted in both closed-set and open-set settings. In the closed-set scenario, the model will classify audio produced by generators that were present during training. In the open-set scenario, we will test how the system behaves when it encounters audio from a generator that was not included in the training data.
