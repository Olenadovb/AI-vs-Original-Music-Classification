## Repository structure

```
.
├── src/
│ └── ai_music_origin/ # project source code
|
├── scripts/               # data preparation and experiment scripts
├── app/                   # optional demo application
├── notebooks/             # exploratory analysis and research notebooks
├── tests/                 # test_data.py, test_models.py, test_reproducibility.py
├── config/                # experiment configuration
├── data/                  # raw data NOT committed; data/README.md 
├── models/                # trained models/checkpoints; not committed 
├── results/               # figures, metrics, and experiment summaries
├── docs/                  # proposal/, poster/, slides/, CONTRIBUTING.md, and this file's supporting docs
└── .github/workflows/     
```
## Quick start

```bash
git clone <repo-url> && cd AI-vs-Original-Music-Clasification

python -m venv .venv source 

.venv/bin/activate # macOS / Linux 
.venv\Scripts\activate # Windows

pip install -r requirements.txt
```
