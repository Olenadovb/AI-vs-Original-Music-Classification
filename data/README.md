# Data card

This file describes the data used in the project, where it comes from, under which terms it can be used, and how to obtain it. The data itself is not stored in the repository.

**FakeMusicCaps** was created by researchers at Politecnico di Milano for the detection and attribution of synthetic music. It contains audio generated by five text-to-music models from the text captions of MusicCaps. It is our main dataset.

**MusicCaps** is a set of 5,521 music descriptions written by professional musicians for 10-second YouTube clips. We use only its metadata file (`musiccaps-public.csv`) to attach the original text prompt to each generated clip. We do not download any YouTube audio.

## Size and format

- 27,605 audio clips: 5,521 prompts × 5 generators, 5,521 clips per generator.
- Generators: `MusicGen_medium`, `audioldm2`, `musicldm`, `mustango`, `stable_audio_open`.
- WAV, mono, 16 kHz, 32-bit float.
- Duration is 10.0 s for AudioLDM2, MusicLDM and Stable Audio Open, about 10.18 s for MusicGen and about 10.24 s for Mustango. Before feature extraction, all clips are trimmed or padded to exactly 10 s, so that duration cannot be used as a shortcut.

## How to get it

From the project root:

```bash
python scripts/download_data.py
```

The script downloads `FakeMusicCaps.zip` and verifies its MD5 checksum (`db418dc95ab7dc378a55f29d6021fd66`), and then downloads `musiccaps-public.csv`. Files that are already present are not downloaded again.

Next, extract the archive manually so that the structure looks like this:

```
data/raw/
├── FakeMusicCaps.zip
├── musiccaps-public.csv
└── fakemusiccaps/
    ├── MusicGen_medium/   *.wav
    ├── audioldm2/         *.wav
    ├── musicldm/          *.wav
    ├── mustango/          *.wav
    └── stable_audio_open/ *.wav
```

The archive also contains a `__MACOSX` folder, which is ignored.

## Folder layout

| Folder | Contents | Created by |
|---|---|---|
| `data/raw/` | Downloaded archive, extracted audio, MusicCaps metadata | `scripts/download_data.py` |
| `data/interim/` | Metadata tables, splits, features and embeddings | notebooks `01`, `02` and `scripts/prepare_dataset.py` |

Main files in `data/interim/`:

| File | Description |
|---|---|
| `audio_analysis.csv` | One row per clip: `track_id`, `generator`, `path`, `caption`, and audio statistics (duration, sample rate, peak and RMS amplitude) |
| `split_metadata.csv` | Same clips with a `split` column (`train` / `validation` / `test`) |
| `pilot_metadata.csv` | Balanced subset of 600 prompts (3,000 clips) for quick experiments |
| `handcrafted_features_full.csv` | 36 acoustic features per clip |
| `clap_embeddings_full.npz`, `mert_embeddings_full.npz`, `muq_embeddings_full.npz` | Embeddings (512-, 768- and 1,024-dimensional) with `track_ids`, `generators` and `splits` arrays |

Files without the `_full` suffix are the pilot-subset versions.

## Splits

`scripts/prepare_dataset.py` splits the data 70 / 15 / 15 at the **prompt level** with seed 42. All five generator versions of a prompt always fall into the same split, so a prompt seen in training never appears in validation or test. The script also checks that classes are balanced in every split and that no caption is shared across splits.

| Split | Prompts | Clips |
|---|---:|---:|
| train | 3,864 | 19,320 |
| validation | 828 | 4,140 |
| test | 829 | 4,145 |

An existing split is reused by default. Rebuilding it requires the `--resplit` flag.

## Personal data

The audio in FakeMusicCaps is fully synthetic and does not contain recordings of real people. Some clips contain generated vocals, but these are not recordings of real voices.

MusicCaps metadata includes YouTube video IDs (`ytid`), which link to publicly available videos. We use them only as track identifiers and do not download or process the original videos. The captions describe music and contain no personal information.

## Scraping

Not applicable. All data comes from published research datasets and is downloaded from their official pages.

## Known limitations and biases

- **Five generators only.** The data covers five models from 2023–2024. Commercial services (Suno, Udio) and newer models are not included, so results may not transfer to them.
- **One prompt set.** All clips are generated from MusicCaps captions, which are tied to the musical styles in AudioSet. Some genres are better represented than others.
- **Generator-specific technical differences.** Apart from duration, generators differ in loudness (for example, Stable Audio Open is the loudest on average, and some MusicGen and Stable Audio Open clips have peaks above 1.0). These differences may help classification without reflecting deeper "fingerprints". We do not normalise amplitude by default.
- **No real music in the main experiments.** The project distinguishes generators from one another but does not yet include human-made music.

## Ethical risks

A system that attributes music to a specific generator could be used to judge whether a piece was made with AI. A wrong prediction could lead to a false accusation against a musician, and the system has only been tested on five known generators. It should not be used as evidence about the origin of a specific track, for example in copyright disputes or on music platforms, without further validation on real and unseen data.
